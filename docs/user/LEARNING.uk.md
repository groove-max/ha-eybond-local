# Shadow Learning: додавання відсутніх контролів

[English](LEARNING.md)

Коли локальні показання працюють, але налаштування бракує, **Write Controls**
може визначити команди хмарного застосунку та створити локально підтверджені
контроли для цього пристрою. Доступність залежить від профілю, транспорту й
хмарного провайдера. Для звичайного локального моніторингу навчання не потрібне.

## Оберіть потрібне завдання

| Завдання | Результат |
|---|---|
| Лише читання / Аналіз даних пристрою | Хмарні метадані та докази для діагностики. Не додає сутності або контроли автоматично. |
| Write Controls / Перевірка додаткового локального керування | Захищена активна перевірка; придатні локально підтверджені результати можна застосувати до пристрою. |

Для відсутнього хмарного налаштування обирайте активну перевірку, якщо вона
доступна. Попередній read-only аналіз не обов'язковий. Одна перехоплена команда
не підтверджує всі значення, всі параметри чи сумісність з іншим інвертором.

## Перед активним навчанням

- Перевірте стабільні показання й достатню пам'ять HA. Поточний тестовий
  механізм потребує 400 MiB доступної RAM, а не загального обсягу пам'яті.
- Закрийте застосунок виробника; не змінюйте налаштування через іншу інтеграцію.
- Прийміть зміну endpoint і можливу перерву хмарного доступу.
- Забезпечте можливість перевірити інвертор та відновити з'єднання.
- Не запускайте тест, якщо перерва може загрожувати критичному навантаженню.

Тестові команди запису мають перехоплюватися захищеним механізмом, а не
передаватися інвертору як звичайне хмарне керування. Не обходьте перевірки
готовності та не вважайте будь-яку невдачу дозволом негайно повторювати спробу.

## Запуск і результат

Відкрийте **Налаштувати → Розширити підтримку пристрою** та активну перевірку
керування. Назви залежать від версії та мови. Оберіть доступне джерело хмари,
прочитайте попередження й авторизуйтеся на цей сеанс. Пароль не зберігається.
Деякі облікові записи працюють і в SmartESS, і в DESSMonitor; обирайте лише
джерело, запропоноване й підтверджене майстром для вашого пристрою.

Перед застосуванням перегляньте результати. Навчені контроли належать лише
цьому пристрою HA, доки їхні докази не перевірять для додавання до каталогу.

## Якщо хмара використовує інший протокол

Інвертор може відповідати локально через PI30, а хмара — працювати через
Modbus. Підтверджена перевірка може запропонувати інший профіль, наприклад
0925. Вона не перемикає його автоматично, не перекладає довільні команди та
не доводить роботу всіх записів. Перед вибором порівняйте показання кандидата.
Якщо сумісну карту не знайдено, залиште поточний профіль. Підтримка навчання
для нового профілю перевіряється окремо від телеметрії.

## Відновлення й захищений повтор

У поточному тестовому коді 0.3 автоматичне відновлення потребує підтвердженого
завершення кожної надісланої тестової команди. За невизначеного результату
колектор може залишитися локальним **навіть після успішного сканування чи
перезапуску HA**. Локальна телеметрія й підтримуване керування залишаються,
але хмара може бути вимкненою до перевіреного відновлення. Це не Cloud Bridge.

Повторюйте навчання під захистом лише коли це пропонує майстер. Не видаляйте
файли відновлення, не змінюйте endpoint примусово й не перезапускайте HA заради
зняття захисту. При невдачі збережіть стан і створіть один [пакет підтримки](HELP.uk.md).
[Детальний англомовний довідник](DEVICE_LEARNING.md) пояснює обмеження й стани.
Опублікована beta.5 може не містити нових виправлень: [перевірте канал](INSTALLATION.uk.md).

# Встановлення й оновлення EyeBond Local

[English](INSTALLATION.md)

EyeBond Local — користувацька інтеграція Home Assistant, не застосунок/add-on.
HACS необов'язковий. Потрібні сумісний колектор EyeBond, мережевий доступ та
резервна копія перед зміною наявної інсталяції.

## Спочатку оберіть версію

| Канал | Поточна публікація | Коли обирати |
|---|---|---|
| Стабільний реліз | [0.1.53](https://github.com/groove-max/ha-eybond-local/releases/tag/v0.1.53) | Свідомо потрібна старіша стабільна версія; багатьох нових виправлень у ній немає. |
| Опублікована бета 0.3 | [0.3.0-beta.5](https://github.com/groove-max/ha-eybond-local/releases/tag/v0.3.0-beta.5) | Потрібна опублікована попередня версія 0.3, а її обмеження прийнятні. |
| Поточний `main` | Неопублікована розробка 0.3 | Розробник попросив перевірити нове виправлення або ви свідомо обрали тестовий код. |
| Cloud Bridge 0.4 | Окрема розробка | Не входить до цих інструкцій чи публічних можливостей 0.3. |

GitHub **Latest release** не враховує prerelease та зараз відкриває 0.1.53.
У `main` manifest може й далі містити beta.5, хоча код новіший: у звіті вказуйте
також коміт. Ці посібники описують поточну розробку 0.3; не всі можливості
обов'язково є в опублікованій beta.5. Нові публікації та вимоги шукайте у
[списку релізів](https://github.com/groove-max/ha-eybond-local/releases).

## Через HACS

1. Встановіть HACS окремо, якщо ще не користуєтеся ним.
2. Відкрийте HACS і **Custom repositories** у меню.
3. Додайте `https://github.com/groove-max/ha-eybond-local`, категорія **Integration**.
4. Знайдіть **EyeBond Local**, оберіть потрібну версію й завантажте. Якщо бети
   немає у списку, увімкніть показ beta/prerelease у діалозі вибору версії.
5. Перезапустіть HA й відкрийте **Налаштування → Пристрої та служби → Додати інтеграцію → EyeBond Local**.

[Відкрити репозиторій у HACS](https://my.home-assistant.io/redirect/hacs_repository/?owner=groove-max&repository=ha-eybond-local&category=integration).
Це користувацький репозиторій, а не запис у стандартному списку HACS.

## Вручну

1. Завантажте ZIP обраного релізу за посиланням вище.
2. Скопіюйте лише `custom_components/eybond_local/` до `custom_components/`
   у каталозі конфігурації HA.
3. Перевірте шлях: `config/custom_components/eybond_local/manifest.json`.
4. Повністю перезапустіть HA й додайте інтеграцію.

Не вкладайте зайвий каталог репозиторію чи `custom_components` усередину.
Резервні копії тримайте **поза** `custom_components`: перейменований каталог
зі старим manifest HA теж може розпізнати як інтеграцію.

## Тестування main

Зробіть резервну копію, завантажте [ZIP main](https://github.com/groove-max/ha-eybond-local/archive/refs/heads/main.zip)
та замініть повний каталог `eybond_local` на каталог з архіву. Не змішуйте
файли різних версій. Повністю перезапустіть HA: перезавантаження лише запису
інтеграції не оновлює всі Python-модулі. Для оновлення не треба видаляти й
заново додавати пристрої. У звіті вкажіть перевірений коміт.

Встановлена вручну копія main не отримує наступні коміти автоматично.
Релізи через HACS та знімки main — різні канали.

## Оновлення й повернення

Збережіть резервну копію HA та номер попередньої версії. Оновіть через HACS
або повною заміною каталогу, перезапустіть і перевірте показання.
Для повернення встановіть обрану опубліковану версію, перезапустіть HA та за
потреби відновіть резервну копію. Заміна коду сама по собі не знімає захист
навчання й не скасовує зміну endpoint: дотримуйтеся показаного стану відновлення.

Далі: [перше підключення](GETTING_STARTED.uk.md) та [сумісність](COMPATIBILITY.uk.md).

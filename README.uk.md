> **Картка для дашборду:** [EyeBond Local Card](https://github.com/groove-max/ha-eybond-local-card) додає готовий дашборд Home Assistant з потоками енергії та графіками.

**EyeBond Local** — інтеграція Home Assistant для гібридних інверторів, які працюють через Wi-Fi-колектори SmartESS / EyeBond.

Вона читає дані інвертора через локальну мережу. Для підтримуваних моделей також доступне безпечне керування: ліміти заряду, режим виходу, звуковий сигнал та інші налаштування, які підтримує саме ваш інвертор.

Якщо ваш інвертор уже працює в застосунку SmartESS, є хороший шанс, що він запрацює і тут.

> **Примітка:** Інтеграція активно розвивається. Частина інверторів підтримується повністю, частина — лише для читання, а для частини потрібен архів підтримки.

---

## Що вміє інтеграція

- Читає дані інвертора, батареї, PV, навантаження та мережі локально.
- Створює звичайні сутності Home Assistant: сенсори, числа, списки вибору, перемикачі та кнопки.
- Підтримує два режими колектора:
  - **SmartESS + HA** — SmartESS і Home Assistant працюють разом.
  - **HA only** — колектор працює тільки з Home Assistant.
- Дає вибрати рівень керування:
  - **Read-only** — лише моніторинг.
  - **Auto** — перевірене керування вмикається автоматично.
  - **Full Control** — ручне відкриття доступних елементів керування для досвідчених користувачів.
- Може створити **архів підтримки**, якщо пристрій потребує діагностики або додавання підтримки.
- Працює з додатковою карткою [EyeBond Local Card](https://github.com/groove-max/ha-eybond-local-card).

## Підтримуване обладнання

EyeBond Local призначена для інверторів, які використовують SmartESS / EyeBond-сумісні Wi-Fi-колектори. Це може бути окремий колектор або вбудований Wi-Fi-модуль.

Поточний список моделей:

- [Каталог моделей інверторів](docs/generated/INVERTER_MODEL_CATALOG.generated.md)

Під час налаштування інтеграція показує, що вдалося визначити:

- **Supported** — нормальний моніторинг і підтверджене керування.
- **Limited / partial** — моніторинг працює, але частина сенсорів або керування може бути відсутня.
- **Read-only** — моніторинг працює, керування вимкнене.
- **Unknown** — потрібен архів підтримки для перевірки.

Якщо вашої моделі немає у списку, вона все одно може працювати. Додайте пристрій, створіть архів підтримки й відкрийте GitHub issue.

### Немає заводського колектора?

Якщо у вашого інвертора немає SmartESS / EyeBond-колектора, можна використати спільнотний [ESP EyeBond Collector](https://github.com/groove-max/esp-eybond-collector).

Це невеликий міст на ESP8266/ESP32, який підключається до інвертора і працює з цією інтеграцією локально. Оскільки він не використовує хмару SmartESS, доступні тільки локальні функції Home Assistant.

## Встановлення

### Через HACS

1. Відкрийте **HACS → Integrations**.
2. Натисніть меню → **Custom repositories**.
3. Додайте `https://github.com/groove-max/ha-eybond-local` як **Integration**.
4. Знайдіть **EyeBond Local** і натисніть **Download**.
5. Перезапустіть Home Assistant.
6. Перейдіть у **Settings → Devices & Services → Add Integration** і знайдіть **EyeBond Local**.

### Ручне встановлення

1. Завантажте останній реліз.
2. Скопіюйте `custom_components/eybond_local/` у `config/custom_components/`.
3. Перезапустіть Home Assistant.
4. Додайте **EyeBond Local** через **Settings → Devices & Services**.

## Налаштування

Майстер налаштування спочатку знаходить колектор, а потім підтверджує інвертор.

### 1. Підключіть колектор до тієї самої мережі

Якщо колектор уже в тій самій Wi-Fi/LAN-мережі, що й Home Assistant, продовжуйте.

Якщо ні — скористайтеся застосунком SmartESS, ручним налаштуванням Wi-Fi або Bluetooth-налаштуванням, якщо ваш колектор це підтримує.

<p align="center"><img src="docs/images/setup-02-collector-network.png" alt="Вибір способу підключення колектора до мережі" width="480"></p>

<p align="center"><img src="docs/images/setup-03-bluetooth-wifi.png" alt="Налаштування Wi-Fi через Bluetooth" width="480"></p>

### 2. Проскануйте мережу

Виберіть мережевий інтерфейс Home Assistant і запустіть пошук. Швидке сканування зазвичай займає кілька секунд. Якщо нічого не знайдено, спробуйте глибоке сканування або ручне налаштування.

<p align="center"><img src="docs/images/setup-04-scan-interface.png" alt="Вибір інтерфейсу сканування" width="480"></p>

<p align="center"><img src="docs/images/setup-05-scanning.png" alt="Сканування мережі" width="480"></p>

### 3. Перевірте результат

Майстер може показати:

- **Ready** — пристрій знайдено і його можна додати.
- **Review** — пристрій знайдено, але результат варто перевірити.
- **Collector only** — колектор відповів, але інвертор ще не визначено впевнено.

<p align="center"><img src="docs/images/setup-06-detected-devices.png" alt="Виявлені пристрої" width="480"></p>

### 4. Виберіть режим колектора

Виберіть, чи має колектор продовжувати працювати зі SmartESS, чи тільки з Home Assistant.

<p align="center"><img src="docs/images/setup-07-confirm.png" alt="Підтвердження виявлення та вибір режиму колектора" width="480"></p>

Ручне налаштування доступне, коли автоматичний пошук не підходить.

<p align="center"><img src="docs/images/setup-manual.png" alt="Ручне налаштування" width="360"></p>

> **Порада:** Автопошук найкраще працює, коли Home Assistant і колектор у тій самій мережі.

## Після налаштування

EyeBond Local зазвичай створює два пристрої Home Assistant:

- **Колектор** — Wi-Fi, мережеві дії, режим колектора, перезапуск, архів підтримки та дії для діагностики.
- **Інвертор** — сенсори, лічильники енергії, стани та підтримуване керування.

<p align="center"><img src="docs/images/device-overview.png" alt="Колектор та інвертор у Home Assistant" width="720"></p>

На пристрої інвертора можуть бути:

- сенсори PV, навантаження, батареї, інвертора та мережі;
- лічильники енергії для Energy Dashboard;
- аварії, помилки та режим роботи;
- безпечне керування, яке підтримує саме ваша модель;
- інтервал оновлення від `2` до `3600` секунд.

<p align="center"><img src="docs/images/inverter-sensors.png" alt="Сенсори інвертора після налаштування" width="320"></p>

Режим колектора та режим керування можна змінити пізніше в **Runtime settings**.

<p align="center"><img src="docs/images/runtime-settings.png" alt="Параметри роботи" width="480"></p>

## Навчання пристрою

Деякі пристрої спочатку додаються в режимі тільки читання або часткової підтримки. **Add controls (device learning)** може перевірити, які додаткові налаштування та сенсори підтримує саме ваш пристрій.

Використовуйте це, коли:

- інтеграція пропонує це для вашого пристрою;
- моніторинг працює, але керування відсутнє;
- розробник попросив запустити навчання для додавання моделі.

Що відбувається:

1. Відкрийте **Configure → Add controls (device learning)**.
2. Прочитайте попередження про безпеку.
3. Увійдіть у SmartESS для цього одного сеансу.
4. Дочекайтеся перевірки доступних налаштувань.
5. Перегляньте знайдені елементи перед застосуванням.

Пароль SmartESS не зберігається. Знайдені елементи застосовуються тільки до цього пристрою Home Assistant, доки їх не буде перевірено і додано до вбудованого каталогу.

Якщо щось виглядає небезпечно або незрозуміло, зупиніться і створіть архів підтримки.

Повний опис: [Device Learning](docs/DEVICE_LEARNING.md).

## Як отримати допомогу

Якщо щось не працює:

1. Відкрийте інтеграцію в **Settings → Devices & Services**.
2. Натисніть **Configure → Diagnostics and experimental metadata**.
3. Натисніть **Create support archive**.
4. Відкрийте [GitHub issue](https://github.com/groove-max/ha-eybond-local/issues) і прикріпіть ZIP.

Архів підтримки — найкращий спосіб повідомити про непідтримуване обладнання, помилку налаштування, відсутні сенсори або відсутнє керування.

Детальніше: [Support Archive](docs/SUPPORT_ARCHIVE.md).

Шаблони issue:

- **Bug Report** — щось зламалося на вже підтримуваному обладнанні.
- **Support Archive / Hardware Diagnostics** — нове обладнання, невдале налаштування, відсутні сенсори або керування.
- **Feature Request** — покращення UX або нові можливості.

## Усунення проблем

| Проблема | Що спробувати |
|---|---|
| Автопошук нічого не знаходить | Виберіть інший мережевий інтерфейс, потім повторіть швидке або глибоке сканування. За потреби використайте ручне налаштування з IP колектора з роутера. |
| Bluetooth Wi-Fi недоступний | Переконайтеся, що Home Assistant має Bluetooth поруч із колектором. Може допомогти ESPHome Bluetooth Proxy біля колектора. |
| Пристрій лишається в **EyeBond Setup Pending** | Зачекайте кілька хвилин, оновіть сторінку пристрою, потім повторіть сканування або ручне налаштування. Якщо не допомогло — створіть архів підтримки. |
| Статус **Collector only** | Колектор відповів, але інвертор не визначено впевнено. Створіть архів підтримки. |
| Сенсори недоступні | Перевірте, що колектор і Home Assistant у тій самій мережі, а Wi-Fi колектора стабільний. |
| SmartESS перестав показувати дані | Перевірте режим колектора. **HA only** навмисно відключає цей колектор від SmartESS. Перемкніть назад на **SmartESS + HA**, якщо потрібен застосунок виробника. |
| SmartESS працює, а Home Assistant показує недоступність | Колектор міг швидше відновити зв'язок зі SmartESS, ніж локально з Home Assistant. Зачекайте кілька хвилин і перевірте Wi-Fi. |
| Налаштування одразу повертається назад | Інвертор відхилив значення або не підтвердив зміну. Не змінюйте той самий параметр у SmartESS одночасно й повторіть після стабілізації колектора. |
| Потрібне віддалене підключення | Дивіться [посібник Remote / NAT](docs/REMOTE_SETUP.md). За можливості використовуйте VPN замість публічного port forwarding. |
| Немає керування | Для нормального використання залишайте **Auto**. Якщо моніторинг працює, але керування відсутнє, запустіть навчання пристрою, якщо воно доступне, або створіть архів підтримки. **Full Control** використовуйте лише якщо розумієте ризик. |
